# Checklist nhanh trước khi code module mới

- [ ] Đã xác định mục tiêu tính năng
- [ ] Đã xác định input / output
- [ ] Đã xác định API contract
- [ ] Đã xác định bảng DB liên quan
- [ ] FE đã có module riêng
- [ ] BE đã có module riêng
- [ ] Không để business logic nặng ở FE
- [ ] Không để query DB rải trong route
- [ ] Có README cho module
- [ ] Có thể copy module sang dự án khác
