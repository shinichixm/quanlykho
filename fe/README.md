# Frontend (Next.js + TypeScript)

## Cấu trúc
- `src/modules/` -> từng tính năng frontend
- `src/shared/` -> UI và helper dùng chung
- `src/app/` -> App Router của Next.js

## Lưu ý
- UI để trong `components/`
- logic fetch/state để trong `hooks/`
- gọi API để trong `services/`
- type frontend để trong `types/`
