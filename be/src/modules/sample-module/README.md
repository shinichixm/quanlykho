# sample-module (BE)

## Mục đích
Module backend mẫu để đổi thành:
- auth
- user
- payroll
- import-bank

## Cấu trúc
- `routes/` -> endpoint
- `services/` -> xử lý nghiệp vụ
- `repositories/` -> query DB
- `mappers/` -> map output
- `schemas/` -> validate input
- `types/` -> mô tả dữ liệu
- `constants/` -> hằng số
